# Discord Markdown Formatter

A browser workspace for composing Discord-compatible messages and previewing how Discord-specific Markdown will render.

## Language

**Message**:
The Discord text being composed in the editor and rendered in the preview.
_Avoid_: Content, document, body

**Message formatting**:
A user intent that changes a Message by adding, removing, or inserting Discord-compatible Markdown syntax while preserving the user's editing position.
_Avoid_: Text manipulation, selection helper
